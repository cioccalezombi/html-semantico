# Star Wars News Landing Page

Una recreación interactiva de un sitio de noticias de Star Wars, desarrollada como un proyecto de aprendizaje paso a paso para dominar el desarrollo web frontend desde las bases hasta librerías y frameworks modernos.

## Propósito del Proyecto

El objetivo principal de este repositorio es documentar la evolución de una interfaz web, comenzando desde la estructura semántica más básica en HTML puro y avanzando gradualmente hacia aplicaciones web modernas e interactivas.

A través de esta landing page, se aplican buenas prácticas de maquetación, diseño adaptativo, componentización y gestión de estado.

## Hoja de Ruta (Roadmap de Aprendizaje)

El proyecto se divide en las siguientes fases de desarrollo:

* [x] **Fase 1: HTML5 Semántico Puro** *(Actual)*
  * Estructuración limpia utilizando etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
  * Buenas prácticas de accesibilidad y estructura jerárquica de contenido.
  * Organización de recursos multimediales locales.

* [ ] **Fase 2: CSS3 & Diseño Visual**
  * Implementación de la paleta de colores oficial de Star Wars (tonos oscuros y amarillos dorados).
  * Tipografías personalizadas y estilos de navegación.
  * Layouts modernos con Flexbox y CSS Grid.
  * Adaptabilidad para dispositivos móviles (Responsive Design).

* [ ] **Fase 3: Bootstrap 5**
  * Refactorización del diseño utilizando el framework de Bootstrap.
  * Implementación de componentes nativos (Carrusel de noticias, cards, modales).

* [ ] **Fase 4: React & Ecosistema Moderno**
  * Transformación a una aplicación Single Page Application (SPA) con React.
  * Componentización reutilizable de artículos, cabeceras y contadores.
  * Manejo de estado dinámico para la cuenta regresiva (*Star Wars Celebration 2027*).

## Cómo ejecutar el proyecto localmente

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   ```

2. **Navegar a la carpeta del proyecto:**
   ```bash
   cd TU_REPOSITORIO
   ```

3. **Abrir en el navegador:**
   * Abre el archivo `index.html` en tu navegador de preferencia.
   * O utiliza la extensión Live Server en Visual Studio Code para previsualizar los cambios en tiempo real.
